How it works

## What this automation does, step by step

1. Sixty, thirty, and seven days before a policy is set to renew, this automation checks the CRM for any noted change in the client's circumstances, a new vehicle, a new address, a recent life event, and sends a renewal reminder that reflects those specifics rather than a generic notice.
2. Any client whose premium is increasing by more than a set percentage is automatically flagged so the agent calls before the renewal notice arrives cold.
3. Renewal season stops being one mass mailing and becomes a set of targeted, relevant conversations.

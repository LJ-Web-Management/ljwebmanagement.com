How it works

## What this automation does, step by step

1. Every RFI submitted by the contractor is automatically logged with the date received, the question posed, the discipline responsible for the response, and a deadline calculated from the contract's RFI response requirement.
2. Overdue RFIs trigger an escalating sequence of alerts to the responsible engineer and then to the project manager.
3. Approved change orders are logged against the original contract value, and the project engineer receives a running contract value summary that updates automatically with each executed change, so the total project cost picture is always current without anyone manually updating a log.

## The manual way vs. the automated way

### Without automation

Done manually, a project engineer has to remember to follow up on every case individually, often relying on memory, phone calls, and whatever notes didn't get lost. It rarely feels urgent in the moment, but it adds up fast.

### With this automation

- Low-stock and reorder alerts before you run out
- Vendor and subcontractor confirmations that chase themselves
- Preventive maintenance scheduled by usage or date
- Work orders and project milestones that update stakeholders

How it works

## What this automation does, step by step

1. When a return authorization is issued, this automation generates an RMA number, sends the customer a pre-paid label, and creates a pending receipt record in the system.
2. When the return arrives and is scanned in at the returns dock, the supervisor receives a prompt to complete a condition inspection via a mobile form.
3. Based on the inspection result (sellable, refurbish, vendor credit, or destroy) the system automatically routes the unit to the correct disposition queue, initiates the appropriate credit or replacement, and notifies the customer that their return has been processed.
4. Returns that have been received but not inspected for more than 48 hours are flagged for immediate resolution.

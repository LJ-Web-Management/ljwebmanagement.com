How it works

## What this automation does, step by step

1. When a student's grade in the gradebook drops below a set threshold, a parent communication is automatically drafted and sent from the teacher's account, summarizing the current grade, missing assignments, and a suggested next step.
2. Weekly classroom updates are also sent automatically to all parents on a consistent schedule, so the teacher doesn't have to remember to send a newsletter, routine communication happens without eating into planning or grading time.

Tools it connects

- Student information system (e.g., PowerSchool or Skyward)
- Zapier or Make.com
- Gmail (automated parent emails)
- Google Classroom (assignment tracking)
- OpenAI API (personalized draft language)

Using different software? We build around what you already have, so you never have to switch tools to automate.

## The manual way vs. the automated way

### Without automation

Handled by hand, a k-12 teacher spends time each day re-checking the same information across disconnected tools instead of doing higher-value work. None of it is difficult, it's just slow, repetitive, and easy to fall behind on.

### With this automation

- Status updates triggered by real milestones in your systems
- Support requests routed to the right owner with full context
- Escalations when a response deadline is about to slip
- Fewer inbound status calls for your front desk

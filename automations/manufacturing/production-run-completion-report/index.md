How it works

## What this automation does, step by step

1. The moment a production run is marked complete in the MES, this automation pulls the run's total output, scrap rate, downtime minutes, and total time-to-complete, and compares each figure against the target set when the run was scheduled.
2. A summary report, highlighting any run that missed its output target by more than 5% or exceeded its scrap allowance, is compiled automatically and emailed to the plant manager within minutes of the run closing rather than waiting for the end-of-shift paperwork to be manually assembled.
3. Runs that hit or beat every target are flagged as a "clean run" for easy reference when building best-practice documentation.
4. The operations director starts each morning already knowing which lines need attention instead of piecing that picture together from three different shift reports.

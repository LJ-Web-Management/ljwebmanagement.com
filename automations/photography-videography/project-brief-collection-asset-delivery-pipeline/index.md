How it works

## What this automation does, step by step

1. When a new video production is booked, the client receives a structured creative brief form capturing the video's goal, target audience, key messages, tone, reference examples, and all brand assets.
2. Completed briefs are automatically routed to the assigned director and editor with a project folder pre-created in the shared drive.
3. At each production milestone (pre-production complete, rough cut ready, final cut delivered) the client receives an automated status update with a review link and a feedback deadline.
4. Feedback received after the deadline is flagged as a scope extension rather than incorporated silently, protecting the production timeline and the team's workload.

## The manual way vs. the automated way

### Without automation

The manual approach means a video production manager handles each case reactively, after someone has already noticed something went wrong. It rarely feels urgent in the moment, but it adds up fast.

### With this automation

- Low-stock and reorder alerts before you run out
- Vendor and subcontractor confirmations that chase themselves
- Preventive maintenance scheduled by usage or date
- Work orders and project milestones that update stakeholders

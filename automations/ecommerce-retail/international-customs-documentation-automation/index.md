How it works

## What this automation does, step by step

1. The moment an order ships to an international address, this automation automatically generates the required customs paperwork, commercial invoice, HS codes, declared value, using Zonos or Avalara's cross-border compliance engine, pulling the product details directly from Shopify or WooCommerce so nothing has to be typed in by hand.
2. The completed documentation is attached directly to the shipping label generated through EasyPost or ShipStation before it ever reaches the warehouse floor, so the fulfillment team never has to pause an international order to track down paperwork.
3. Zapier or Make.com flags any order with missing or ambiguous product data before it ships, rather than letting it get held at customs.
4. Manual customs paperwork is one of the most error-prone parts of international fulfillment; automating it removes the delays and returned shipments that come from a mistyped HS code or a missing invoice.

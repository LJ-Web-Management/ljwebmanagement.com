How it works

## What this automation does, step by step

1. When a customer starts a return through the store's returns portal, this automation checks the reason given (wrong size, changed mind, defective) and, for size or color issues, automatically offers an instant exchange instead of a refund: the replacement item ships the same day, a prepaid return label for the original goes out by email through EasyPost or ShipStation, and the order in Shopify or WooCommerce is updated to reflect the swap.
2. Only returns that don't qualify for an exchange fall through to a standard refund, which routes to the returns manager for approval once the original item's tracking shows it's back in the warehouse.
3. Offering the exchange first keeps a meaningful share of return revenue in the business instead of losing it to a refund entirely, and it turns what used to be a multi-day email thread into a same-day resolution.

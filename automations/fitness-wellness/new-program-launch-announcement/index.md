How it works

## What this automation does, step by step

1. When a new class or program is added to the schedule, members whose profile matches the relevant interest tags automatically receive an email or text announcement, instead of the program director sending a single generic blast to the entire member list regardless of whether a given member has ever shown interest in that type of class.
2. A new yoga program reaches members who've actually favorited yoga classes before rather than getting lost in a general newsletter, and new program launches fill faster once the announcement lands specifically with the members most likely to actually show up.

## The manual way vs. the automated way

### Without automation

The manual approach means a program director handles each case reactively, after someone has already noticed something went wrong. It rarely feels urgent in the moment, but it adds up fast.

### With this automation

- Win-back sequences triggered by inactivity, not guesswork
- Renewals and memberships that never lapse silently
- Referral and loyalty programs that track themselves
- Segmented campaigns built from actual purchase history

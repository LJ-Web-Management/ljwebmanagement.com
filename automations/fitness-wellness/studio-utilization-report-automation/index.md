How it works

## What this automation does, step by step

1. The automation automatically compiles room and studio usage data to identify underused time slots, giving management data-backed opportunities for adding new classes instead of scheduling decisions being made purely on instinct about which times "feel" slow.
2. A studio manager can see exactly which rooms sit empty at which hours across the week, turning a vague sense that "mornings feel quiet" into a specific, actionable opportunity to test a new class in a slot that's actually available and underused.

## The manual way vs. the automated way

### Without automation

Done by hand, this depends entirely on a studio manager remembering to check in, update records, and follow up, with no safety net if something slips. It rarely feels urgent in the moment, but it adds up fast.

### With this automation

- Daily and weekly digests delivered automatically
- Threshold alerts when a key number moves
- Dashboards fed directly from your systems
- Client and owner reports assembled without copy and paste

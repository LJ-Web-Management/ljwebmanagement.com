How it works

## What this automation does, step by step

1. For car washes offering a rain-check guarantee, this automation automatically checks local weather data against wash dates and proactively texts eligible customers with a free rewash code if rain falls within the guarantee window.
2. Customers stop having to remember and ask; the code just shows up when they've earned it.

Tools it connects

- A weather API
- [Twilio (SMS)](https://www.ljwebmanagement.com/automations/tools/twilio/)
- Zapier or Make.com
- A car wash POS

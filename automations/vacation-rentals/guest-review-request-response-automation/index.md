How it works

## What this automation does, step by step

1. After checkout, this automation automatically requests a review from the guest, and separately drafts a suggested response to any review the host receives, positive or negative, for the host to approve and post.
2. Response time stays fast and consistent instead of depending on the host remembering to check the listing.

Tools it connects

- Hospitable or Guesty
- OpenAI API (response drafting)
- Zapier or Make.com

Using different software? We build around what you already have, so you never have to switch tools to automate.

## The manual way vs. the automated way

### Without automation

Without this system, a guest experience manager manually pieces together information from different places, then has to relay it to everyone who needs it.

### With this automation

- Review requests timed to the moment the job is done
- Instant manager alerts when a customer reports a problem
- Alerts when a new review needs a response
- Survey and NPS results that reach the people who can act

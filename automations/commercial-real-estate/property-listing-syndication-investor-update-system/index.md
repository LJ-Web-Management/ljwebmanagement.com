How it works

## What this automation does, step by step

1. When a property is listed for sale or lease, this automation syncs the listing details, photos, floor plans, and offering memorandum to every relevant listing platform (LoopNet, CoStar, Crexi) simultaneously, and emails the firm's investor and tenant database with the listing announcement segmented by property type and geography so recipients only receive relevant opportunities.
2. Investors who engage with the listing email receive an automatic follow-up from the broker with an invitation to schedule a property tour or request an OM.
3. Listings that have been on the market more than 60 days without a qualifying tour trigger a price-reduction evaluation prompt to the listing broker, building a systematic process for managing listing freshness.

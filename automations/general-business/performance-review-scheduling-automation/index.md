How it works

## What this automation does, step by step

1. Based on each employee's hire date stored in BambooHR, the system automatically schedules 90-day, annual, and any interim performance review cycles, sending the manager a Google Calendar invite along with a Lattice review form pre-populated with the employee's goals from the last cycle.
2. Reminders go out to both manager and employee a week before the scheduled conversation, and if a review is completed late or skipped entirely, HR gets an automatic Slack alert so it doesn't quietly slip for another year.
3. Organizations that used to run reviews sporadically, if at all, now hit a consistent review cadence for every employee, which shows up directly in better retention and clearer promotion documentation.

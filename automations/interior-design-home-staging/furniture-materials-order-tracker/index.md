How it works

## What this automation does, step by step

1. As items are ordered from various vendors for a project, this automation automatically tracks each item's expected delivery date against the project timeline and flags any delay that would push back the planned install date.
2. The designer finds out about a vendor delay while there's still time to communicate proactively with the client, instead of discovering it the morning of install day when the sofa hasn't arrived.

## The manual way vs. the automated way

### Without automation

Left unautomated, a project manager spends hours on the parts of this job that don't require judgment: copying data, sending reminders, and tracking status by hand. It rarely feels urgent in the moment, but it adds up fast.

### With this automation

- Low-stock and reorder alerts before you run out
- Vendor and subcontractor confirmations that chase themselves
- Preventive maintenance scheduled by usage or date
- Work orders and project milestones that update stakeholders

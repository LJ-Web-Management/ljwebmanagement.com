How it works

## What this automation does, step by step

1. When a new design project is onboarded, this automation generates a project timeline with milestones (concept presentation, design development, procurement, installation, and reveal) and sends the client a link to their personal project portal where they can track progress in real time.
2. At each milestone, the client receives a notification with what to expect, what decisions are needed, and any approvals required before the project can advance.
3. Client approvals are captured digitally with a timestamp, and any milestone where approval is delayed triggers an alert to the designer so the project timeline can be adjusted before the delay compounds into a procurement problem.

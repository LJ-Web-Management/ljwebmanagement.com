How it works

## What this automation does, step by step

1. When a real estate agent or homeowner requests a staging consultation, this automation books the consultation on the stager's calendar, sends a pre-consultation questionnaire capturing the home's size, listing timeline, and style preference, and confirms the appointment with directions and what to expect.
2. When staging is confirmed, the system cross-references the project's room list against the furniture inventory database to identify available pieces, flags any items that need to be sourced or rented, and generates a pick list for the installation crew.
3. Available inventory is never double-booked for overlapping projects because the system tracks what is deployed, where, and when it returns.

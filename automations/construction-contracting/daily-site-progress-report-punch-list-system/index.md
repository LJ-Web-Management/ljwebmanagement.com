How it works

## What this automation does, step by step

1. Field supervisors submit a simple daily report form from the job site, and the system automatically formats it into a branded progress report, appends any uploaded photos, and emails it to the owner, architect, and project manager, keeping all stakeholders informed without anyone having to manually format a report or remember to send it.
2. At project end, the punch list is built automatically from flagged items in those daily reports, with trades assigned to each item.

## The manual way vs. the automated way

### Without automation

Without this system, a project manager manually pieces together information from different places, then has to relay it to everyone who needs it. It rarely feels urgent in the moment, but it adds up fast.

### With this automation

- Low-stock and reorder alerts before you run out
- Vendor and subcontractor confirmations that chase themselves
- Preventive maintenance scheduled by usage or date
- Work orders and project milestones that update stakeholders

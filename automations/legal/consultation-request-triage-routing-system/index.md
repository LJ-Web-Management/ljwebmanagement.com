How it works

## What this automation does, step by step

1. When a prospective client submits a consultation request through the firm's website form in Jotform, the automation reads the practice area field and instantly routes the request to the correct attorney or paralegal queue in Clio Grow, tagging urgent matters like an eviction with a hearing date or an upcoming arraignment for same-day callback.
2. A Zapier workflow starts an internal countdown the moment the request lands, and if no one has logged a response within the firm's target window, it automatically escalates with a Slack alert to the intake coordinator and, if still unanswered, to the managing partner.
3. Every request and response time logs to a running Google Sheets dashboard so leadership can see exactly where bottlenecks happen.
4. Firms running this catch same-day, high-urgency matters that used to sit in a shared inbox until someone happened to check it, and average response time typically drops from hours to minutes.

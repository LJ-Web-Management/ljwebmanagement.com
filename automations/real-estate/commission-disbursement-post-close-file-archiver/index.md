How it works

## What this automation does, step by step

1. Once a transaction closes, this automation pulls the final settlement statement, calculates commission splits per the agreement on file, generates a commission disbursement authorization for the broker, and sends it for e-signature, all within an hour of the recorded close date.
2. The complete transaction file is automatically organized in a named cloud folder, a post-close survey is sent to buyer and seller, and a review request goes out 48 hours later.
3. What used to be a half-day of post-close admin is done before the TC finishes their coffee.

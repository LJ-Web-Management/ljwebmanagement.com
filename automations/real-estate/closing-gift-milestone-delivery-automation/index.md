How it works

## What this automation does, step by step

1. The moment a transaction's status changes to closed, the automation automatically triggers an order for a client closing gift through the brokerage's preferred vendor, timed and shipped to arrive right around the actual closing date instead of showing up randomly a few weeks later.
2. The client experience manager sets the gift tier and personalization once per client type: first-time buyer, repeat client, referral source, and the system handles selecting the right gift, adding a personalized card, and confirming delivery automatically from there.
3. A confirmation email lets the agent know exactly when the gift will arrive so they can follow up personally around the same time.
4. What used to be a manual task an agent handled between showings, sometimes forgotten entirely during a busy month, now happens for every closing without anyone having to remember.

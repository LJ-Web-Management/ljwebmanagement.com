How it works

## What this automation does, step by step

1. Every time a lockbox on a listing is opened, the automation automatically logs the exact time, date, and the agent credentials used to access it, then instantly notifies the listing agent by text that a showing has just occurred and who accessed the property.
2. The security and access coordinator gets a running log of every entry across the entire active listing portfolio, making it easy to spot unusual access patterns, such as an entry outside normal showing hours, and follow up immediately rather than discovering a problem days later.
3. Sellers appreciate knowing in real time when their home was shown, and listing agents can immediately follow up with the showing agent for feedback while the visit is still fresh.
4. What used to require pulling a lockbox report manually at the end of the week now delivers real-time visibility the moment it happens.

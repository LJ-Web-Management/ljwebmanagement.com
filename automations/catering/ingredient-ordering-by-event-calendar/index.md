How it works

## What this automation does, step by step

1. Based on the confirmed menus and headcounts for all upcoming events in a given week, this automation automatically compiles the combined ingredient order needed and generates a purchase list for the kitchen manager.
2. Manual math done event-by-event, which is where ordering mistakes creep in during a busy week, gets replaced by one consolidated list.

## The manual way vs. the automated way

### Without automation

Manually, a kitchen manager is stuck doing repetitive follow-ups and data entry that could otherwise run quietly in the background. None of it is difficult, it's just slow, repetitive, and easy to fall behind on.

### With this automation

- Low-stock and reorder alerts before you run out
- Vendor and subcontractor confirmations that chase themselves
- Preventive maintenance scheduled by usage or date
- Work orders and project milestones that update stakeholders

How it works

## What this automation does, step by step

1. Based on each event's size and service style, this automation automatically calculates the number of staff needed, checks availability among the on-call team, and sends shift confirmation requests, flagging the event manager if a shift goes unfilled close to the date.
2. An unfilled shift gets caught with enough lead time to actually solve it.

Tools it connects

- A staffing/scheduling tool (When I Work)
- [Twilio or email](https://www.ljwebmanagement.com/automations/tools/twilio/)
- Zapier or Make.com

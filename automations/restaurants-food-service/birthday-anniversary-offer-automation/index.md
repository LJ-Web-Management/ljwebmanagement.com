How it works

## What this automation does, step by step

1. Roughly a week ahead of a loyalty member's birthday or dining anniversary, the system automatically pulls the date from the loyalty platform and sends a personalized offer, a free dessert, a bottle of wine, or a percentage off, timed to encourage booking a celebration visit rather than arriving as a surprise the same day it's meant to be used.
2. Redemption is tracked automatically at the POS so the marketing team can see exactly how many of these targeted offers convert into an actual reservation, turning a birthday database that used to sit untouched into a reliable source of booked covers every single week.

Tools it connects

- Loyalty platform (e.g., Punchh or Toast Loyalty)
- Zapier or Make.com
- [Mailchimp (birthday email)](https://www.ljwebmanagement.com/automations/tools/mailchimp/)
- POS system (e.g., Toast or Square)

## The manual way vs. the automated way

### Without automation

Manually, a loyalty program manager is stuck doing repetitive follow-ups and data entry that could otherwise run quietly in the background. It rarely feels urgent in the moment, but it adds up fast.

### With this automation

- Win-back sequences triggered by inactivity, not guesswork
- Renewals and memberships that never lapse silently
- Referral and loyalty programs that track themselves
- Segmented campaigns built from actual purchase history

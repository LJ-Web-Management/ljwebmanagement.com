How it works

## What this automation does, step by step

1. This automation tracks how long each candidate has sat in a given pipeline stage, submitted, interviewing, offer pending, and automatically flags anyone who's gone quiet past a set number of days, typically five for an active interview stage.
2. The recruiter gets a prompt to follow up before a strong candidate quietly accepts an offer elsewhere without anyone at the agency realizing the candidate had gone cold.
3. Pipelines that used to rely on a recruiter's memory to catch a stalled candidate now surface the problem automatically.

How it works

## What this automation does, step by step

1. When a guest is confirmed for the podcast, this automation sends them an automated prep packet (the recording link, technical requirements, topic outline, and pre-interview questionnaire) and adds a calendar event to both the host and guest simultaneously.
2. After the episode records, the audio file triggers a production workflow: transcription is initiated, show notes are drafted from the transcript via AI, the episode is uploaded to the hosting platform, and a social media teaser asset is generated, all before the producer has to manually touch the file.
3. The week the episode airs, cross-promotion emails to the guest's audience and the pod's subscriber list go out automatically.

Based on the confirmed menus and headcounts for all upcoming events in a given week, this automation automatically compiles the combined ingredient order needed and generates a purchase list for the kitchen manager. Manual math done event-by-event, which is where ordering mistakes creep in during a busy week, gets replaced by one consolidated list.

Event Crew Staffing Assignment

Based on each event's size and service style, this automation automatically calculates the number of staff needed, checks availability among the on-call team, and sends shift confirmation requests, flagging the event manager if a shift goes unfilled close to the date. An unfilled shift gets caught with enough lead time to actually solve it.
